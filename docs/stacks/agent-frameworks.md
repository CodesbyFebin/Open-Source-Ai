# Agent Frameworks

Libraries for building single and multi-agent systems.

## Quick start

Pick a framework (`pip install crewai` / `langgraph` / `smolagents`) and set `OPENAI_BASE_URL` to your gateway to use any model.

## Get the code

```bash
git clone https://github.com/CodesbyFebin/Open-Source-Ai
cd Open-Source-Ai
git submodule update --init --depth 1 stacks/agent-frameworks
```
