# Memory

Long-term memory layers for agents.

## Quick start

Add persistent memory: `pip install mem0ai`, then `Memory().add(...)` / `.search(...)` inside your agent loop.

## Get the code

```bash
git clone https://github.com/CodesbyFebin/Open-Source-Ai
cd Open-Source-Ai
git submodule update --init --depth 1 stacks/memory
```
