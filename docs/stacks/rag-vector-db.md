# RAG & Vector Databases

Retrieval, indexing and vector stores.

## Quick start

Run a vector DB (`docker run -p 6333:6333 qdrant/qdrant`) and index documents with LlamaIndex or Haystack.

## Get the code

```bash
git clone https://github.com/CodesbyFebin/Open-Source-Ai
cd Open-Source-Ai
git submodule update --init --depth 1 stacks/rag-vector-db
```
