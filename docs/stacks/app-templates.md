# App Templates & Examples

Ready-made AI apps and examples.

## Quick start

Browse ready-made apps, copy one into your project, and swap the model endpoint for your gateway.

## Get the code

```bash
git clone https://github.com/CodesbyFebin/Open-Source-Ai
cd Open-Source-Ai
git submodule update --init --depth 1 stacks/app-templates
```
